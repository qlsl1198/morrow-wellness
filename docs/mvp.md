# 해커톤 MVP

## 핵심 데모 흐름

1. Apple Watch에서 `피로` 상태와 `수면 부족` 원인을 선택한다.
2. iPhone이 HealthKit 데이터와 최근 7일 개인 기준선을 비교한다.
3. AI가 체크인과 변화 데이터를 묶어 오늘의 타임라인을 만든다.
4. 지금 가능한 행동 하나를 추천한다.
5. PC 웹에서 타임라인과 주간 패턴을 확인한다.
6. 추천 수행 후 도움 여부를 남기고 기록을 수정하거나 삭제한다.

## MVP 포함

- 심박, 안정 시 심박, HRV, 수면, 걸음 수 권한 요청 골격
- 단답형 상태 및 원인 체크인
- 최근 7일 평균 대비 변화 표시
- 오늘의 웰니스 타임라인
- 저위험 회복 행동 추천
- 추천 수행 결과 피드백
- 주간 패턴 리포트
- 개별 기록 및 전체 데이터 삭제 API

## MVP 제외

- 질환 또는 정신건강 진단
- 약물 및 치료 지시
- 24시간 실시간 감시
- 생체 신호만으로 스트레스 확정
- 자동으로 외부 사람에게 데이터를 전송하는 기능
