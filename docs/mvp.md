# 해커톤 MVP

## 핵심 데모 흐름

1. 계정 ID로 로그인하고 설정의 코드로 iPhone·Watch·웹을 연결한다.
2. Apple Watch에서 `피로` 상태와 `수면 부족` 원인을 선택한다.
3. iPhone이 HealthKit 데이터와 최근 7일 개인 기준선을 비교해 멱등 동기화한다.
4. AI가 체크인·건강 변화·과거 효과를 묶어 지금 가능한 행동 하나를 추천한다.
5. Watch 또는 iPhone 알림에서 추천 행동을 바로 실행한다.
6. PC 웹에서 KST 타임라인, 수면·운동 상세와 주간 패턴을 확인한다.
7. 추천 수행 후 체감 결과를 남겨 다음 추천에 반영하고 기록을 수정하거나 삭제한다.

## MVP 포함

- 심박, 안정 시 심박, HRV, 수면 단계·구간, 운동 종류·강도, 걸음 수 권한과 집계
- 단답형 상태 및 원인 체크인
- 최근 7일 평균 대비 변화 표시
- 오늘의 웰니스 타임라인
- 저위험 회복 행동 추천
- 추천 수행 결과 피드백
- 주간 패턴 리포트
- 개별 기록 및 전체 데이터 삭제 API
- 계정 ID 로그인, 설정 기반 기기 연결과 기기별 해제
- AI 대화·추천·선제 알림 및 장애 대체 모델

## MVP 제외

- 질환 또는 정신건강 진단
- 약물 및 치료 지시
- 24시간 실시간 감시
- 생체 신호만으로 스트레스 확정
- 자동으로 외부 사람에게 데이터를 전송하는 기능
