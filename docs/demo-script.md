# Morrow Wellness 3분 데모

## 한 문장

Morrow는 Apple Watch의 생체 신호와 30초 자기 보고를 결합해, 사용자가 오늘 바로 실행할 수 있는 작은 회복 행동을 설명 가능하게 제안합니다.

## 0:00–0:30 문제

“웨어러블은 숫자를 많이 보여주지만, 사용자는 결국 ‘그래서 지금 뭘 해야 하지?’를 다시 고민합니다. 반대로 감정 앱은 생체 맥락을 놓칩니다. Morrow는 두 신호를 연결합니다.”

## 0:30–1:10 Watch 체크인

1. iPhone·Watch·웹이 같은 계정으로 연결된 상태를 설정에서 확인합니다.
2. Watch에서 `피곤해요`와 원인 `수면`을 선택합니다.
3. 성공 햅틱과 완료 화면을 보여 줍니다.

강조할 점: 한 손으로 30초 안에 입력하며, 생체 데이터만으로 사용자의 상태를 단정하지 않습니다.

## 1:10–2:00 웹 라이브 보드

1. 웹의 `LIVE API` 표시를 보여 줍니다.
2. 새 체크인이 타임라인에 추가된 모습을 확인합니다.
3. 수면 시작·종료/단계와 운동 종류·강도 상세를 펼쳐 봅니다.
4. 개인화된 추천과 수면·HRV 근거 칩을 보여 줍니다.
5. iPhone 또는 Watch의 `지금 바로 실행`으로 실제 행동 화면을 열고 체감 결과를 남깁니다.

강조할 점: 체크인, 타임라인, 추천이 하나의 실제 API 흐름으로 연결됩니다.

## 2:00–2:35 주간 패턴

주간 리포트로 이동해 상태 변화 차트와 반복 원인을 보여 줍니다. “이번 주 피로 체크인의 주요 원인이 수면이었다”처럼 사용자가 이해할 수 있는 언어로 설명합니다.

## 2:35–3:00 신뢰와 마무리

1. 개인정보 센터에서 전체 데이터 삭제 제어를 보여 줍니다.
2. 위기 표현에는 일반 웰니스 추천 대신 전문 지원 안내가 우선된다고 설명합니다.
3. “Morrow는 진단하는 앱이 아니라, 내일을 조금 더 회복 가능하게 만드는 행동 인터페이스입니다.”로 끝냅니다.

## 실패 대비

- 발표 시작 전 웹 상단이 `LIVE API`인지 확인합니다.
- 발표 계정·세 기기 연결, APNs 상태, 최근 HealthKit 동기화 시각을 미리 확인합니다.
- AI가 일시적으로 제한되면 대체 모델과 안전한 개인화 fallback이 동작하지만, 시연 전 `/assistant/status`의 준비 상태를 확인합니다.
