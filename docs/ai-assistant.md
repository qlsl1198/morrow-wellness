# AI 어시스턴트 시스템

## 개요

Morrow의 AI 어시스턴트는 사용자의 체크인, 타임라인, 피드백 데이터를 지속적으로 학습하여 개인화된 웰니스 조언을 제공합니다.

## 핵심 기능

### 1. 사용자 데이터 학습

AI는 다음 데이터를 실시간으로 분석합니다:

- **체크인 기록** (최근 7일): 상태, 원인, 메모, 시간대
- **타임라인 항목** (최근 7일): AI 생성 인사이트, 사용자 확인 여부
- **추천 피드백** (최근 7일): 완료 여부, 도움 여부, 피드백 메모
- **대화 히스토리** (최근 24시간): 이전 대화 맥락

### 2. 개인화 프롬프트 생성

수집된 데이터를 바탕으로 AI에게 전달되는 컨텍스트:

```
=== 사용자 컨텍스트 ===

최근 7일 체크인 기록:
- 08/07 14:30: 피로 상태, 원인: 수면 (어제 늦게 잠들었음)
- 08/06 09:15: 양호 상태, 원인: 미기록
- 08/05 18:20: 긴장 상태, 원인: 업무 (프로젝트 마감)

최근 타임라인:
- 08:10: 수면 회복이 평소보다 낮음 - 7일 평균보다 1시간 12분 적음
- 13:40: 워치 상태 체크인 - 피로 · 원인: 수면 부족

최근 추천:
- 7분 동안 가볍게 걸어보세요 (상태: COMPLETED)
  근거: 비슷한 피로 상태에서 짧은 걷기가 가장 자주 도움이 됐습니다.
```

### 3. 안전 정책 필터링

AI 응답 생성 전 위험 감지:

#### 위기 상황 감지
키워드: 자살, 자해, 죽고, 끝내고, 사라지고 등

→ **즉시 전문 지원 안내**
```
📞 긴급 지원:
- 정신건강 위기상담: 1577-0199 (24시간)
- 생명의 전화: 1588-9191
- 희망의 전화: 129
- 자살예방상담전화: 1393
```

#### 의료 진단 요청 차단
키워드: 진단, 약, 처방, 치료, 병원 등

→ **의료 전문가 상담 권유**

### 4. OpenAI API 통합

- **모델**: GPT-4o (기본) - 고품질 웰니스 조언
- **온도**: 0.7 (자연스러운 대화)
- **최대 토큰**: 500 (적절한 응답 길이)
- **타임아웃**: 30초

## 설정 방법

### 환경 변수

```bash
# .env 파일 생성
cp backend/.env.example backend/.env

# API 키 설정
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_MODEL=gpt-4o
OPENAI_ENABLED=true
```

### Fallback 모드

OpenAI API 키가 없거나 `OPENAI_ENABLED=false`인 경우:
- 기본 안내 메시지 반환
- 안전 필터는 정상 작동
- 서비스 중단 없이 동작

## 데이터 흐름

```
사용자 메시지
    ↓
안전 필터 검사 (위기/의료)
    ↓ (안전)
사용자 데이터 수집 (7일)
    ↓
컨텍스트 프롬프트 생성
    ↓
OpenAI API 호출
    ↓
개인화된 AI 응답
    ↓
DB 저장 (학습용)
```

## 개인정보 보호

- **데이터 최소화**: 최근 7일만 수집
- **목적 제한**: 개인화된 조언 제공 용도만
- **암호화 전송**: HTTPS 통신
- **외부 학습 금지**: OpenAI 학습 데이터로 사용 안 함
- **삭제권 보장**: 사용자가 언제든 전체 데이터 삭제 가능

## API 사용 예시

### 요청
```json
POST /api/v1/assistant/messages
{
  "userId": "user-123",
  "content": "오늘 피로한데 어떻게 해야 할까요?"
}
```

### 응답 (데이터 학습 후)
```json
{
  "id": "msg-456",
  "userId": "user-123",
  "role": "ASSISTANT",
  "content": "최근 7일 기록을 보니 수면 부족이 주요 원인으로 보입니다. 어제도 비슷한 피로를 느끼셨을 때 7분 걷기가 도움이 되셨다고 하셨죠.\n\n오늘도 짧은 산책을 시도해보시는 건 어떨까요? 또한 오늘 밤은 평소보다 1시간 일찍 잠들어 보세요.",
  "safetyChecked": true,
  "createdAt": "2026-08-07T08:20:00Z"
}
```

## 성능 최적화

- **비동기 처리**: OpenAI 호출 시 타임아웃 설정
- **캐싱**: 자주 사용되는 시스템 프롬프트 재사용
- **페이지네이션**: 대화 히스토리는 최근 24시간만
- **인덱싱**: userId + createdAt 복합 인덱스
